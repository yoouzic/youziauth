# v1.8.28

- 首次安装在安装器已有的管理员授权中配置 SYSTEM 后台和用户托盘任务，保存校园账号无需再次为后台启用请求 UAC。
- 未配置账号或凭据暂不可用时，后台仍可检查更新，校园网认证等待用户完成设置。
- 修复安装完成后后台代理未恢复、后续自动更新停止的问题；安装器按原用户身份恢复已启用的任务。
- 修复真实静默安装返回值与状态解析不一致，安装结果由存活的辅助进程持久记录。
- 修复重启后更新状态丢失和安装结果晚到时被覆盖的问题；保留安装错误、健康检查和重启要求。
- 手动打开 MSI 时显示中文进度与完成、取消或失败结果；自动更新仍使用静默安装。
- 后台更新代理绑定任务所属用户的代理设置，避免多用户环境读取其他账户的代理。
- 将 SYSTEM 写入的更新缓存、日志和运行状态迁至独立的受保护目录，限制用户配置指定的日志路径。
- 安装失败或取消后尝试恢复原后台任务，保留原安装错误；下载超时保留续传文件。
