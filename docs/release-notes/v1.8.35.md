## v1.8.35

- **修复升级会删掉 Python 运行库的严重缺陷**：1.8.34 把 `_internal/python314.DLL` 的大写扩展名当成了新组件，于是升级时「新组件认为已装同版本文件、跳过复制」，紧接着「旧版卸载删掉了它记录在案的那个文件」，Python 运行库从安装目录消失——之后所有安装自定义操作都以 error -1（Could not load Python DLL）失败，整个 MSI 回滚，而回滚前的 taskkill 已经把两个进程杀掉了。现在组件标识只按 Windows Installer 实际记录的文件名（扩展名小写）推导，同一个文件永远只有一个组件
- 升级时若计划任务重启失败，不再让整个安装回滚：该动作改为「尽力而为」，并在最后补一个 `--ensure-agent` 兜底，确保装完机器上一定还有代理在跑
- `schtasks /Create`、`schtasks /Run` 遇到瞬时拒绝会重试三次，而不是直接判定安装失败
- v1.8.34 的校园网认证修复一并包含：登录后回查会话是否真的生效、临时拒绝不再变成静默停摆、无效登录退避并告警
