# 1.9.0
- **新功能**：乐跑 —— 课外跑接入 youziauth，与校园网、寝室打卡并列成为第三个日常模块
- 每天到点自动完成一次课外跑：真门探测凭证 → 生成轨迹（贴校方打卡点）→ 上传 → 提交 → 自动核对学校判定，全程无需盯着
- 跑步设置可调：开始时间（默认 06:30）、距离范围、目标配速（240 秒/公里 ≈ 4'00"）、采点精度，时段外自动拒绝提交
- 跑步凭证加密保存在本机，与寝室打卡同一套 DPAPI 边界：快照只回答「有没有凭证」，绝不含凭证本身
- 凭证跨天复用：实测凭证的有效性只由「小程序重新登录」决定，与提交无关 —— 每次提交后探测一次，活着就留给明天，只有真门返回失效才清除，不再「用完即弃」
- 与乐跑研究库单向同步：身份与凭证以签发时间为准取更新的一方，本机凭证永远是密文
- 今日概览新增「今日乐跑」卡片，运行记录页新增乐跑标签，按天分组展示每次结果
- 后台自动行为有硬上限：每天最多自动尝试 3 次、自动采集 2 次，绝不无限重试
