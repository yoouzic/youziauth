## v1.8.34

- **修复 2026-10-13 通宵认证失败**：门户返回 `result=success` 只代表 ePortal 已受理请求，不再直接算作认证成功。登录后会用返回的 `userIndex` 回查 `getOnlineUserInfo`，只有门户确认会话存在才记录「认证成功」，否则记为「门户已受理，但会话未生效」
- **临时拒绝不再变成静默停摆**：门户答「请稍后再试 / 认证设备响应超时 / 不允许抢占」时按瞬时故障重试；只有账号密码错误这类才阻塞，且阻塞 5 分钟后自动重试（此前需要手动点「重新认证」，曾造成 67 分钟完全无操作、无日志）
- **无效登录退避并告警**：连续 5 次「门户已受理但会话未生效」后按 60/120/300 秒退避，并升级为一次认证失败提醒（此前 8 小时 110 次失败登录没有任何提示）
- 「等待校园网门户」和「认证被阻塞」两个状态补上日志：进入时报一次、之后每 5 分钟一次，不再出现无法与「进程已死」区分的静默
