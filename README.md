# youziauth：西南大学校园网自动认证工具

youziauth 是一款面向西南大学校园网 ePortal 环境的 Windows 自动认证工具。完成一次配置后，它可以在电脑开机时自动检查网络并进行认证，同时提供系统托盘、失败重试和本地凭据保护。

> [!IMPORTANT]
> 本项目由个人开发，是非官方开源工具，与西南大学及校园网运营商无隶属、授权或合作关系。

## 功能特点

- 统一桌面工作台：今日概览、校园网、寝室打卡、运行记录在同一窗口切换；

- 开机后自动检查并认证校园网；
- 已经能够正常访问互联网时自动跳过认证；
- 支持账号、密码和检测间隔设置；
- 支持系统托盘和后台持续检测；
- 认证失败时提供“重新认证”和“打开设置”通知；
- 安装版使用 Windows DPAPI 在本机保护密码；
- 不包含遥测或第三方数据收集功能。
- 寝室打卡：独立学校登录、今日任务查询、实时定位、提交后回查和可选自动执行。

## 寝室打卡（集成预览）

在统一主窗口左侧点击 **寝室打卡**，或从托盘菜单打开 **寝室打卡**。托盘入口会切换到同一个窗口里的打卡页面。

1. 点击 **登录 / 重新登录**，在打开的 Chrome（未安装时使用 Edge）窗口中完成学校统一身份认证。使用独立临时浏览器会话，自动经过学校认证中转页；校园网认证和打卡登录态分别管理。
   - **默认可选**：在面板的「统一认证静默登录」区域保存学号与密码后，登录时会自动填写账号密码并**自动识别验证码**，无需人工输入；最多自动提交 2 次，之后交回人工。凭据用 Windows DPAPI 加密，仅存本机当前用户，可在面板中随时清除（详见 [统一认证静默登录集成说明](docs/captcha-integration.md) 与 [SECURITY.md](SECURITY.md)）。
   - **不保存凭据**时行为与以前完全一致：由你手动输入账号、密码和验证码。
2. 点击 **查询今日任务**，检查任务日期、地点和学校时段。查询不会提交打卡。
3. 点击 **授权并检测定位**。如果 Windows 弹出权限提示，选择允许；已拒绝的权限需要通过 **Windows 定位设置** 重新开启。检测只检查本机实时位置与精度，不提交打卡，也不展示经纬度。成功后查询今日任务，再点击 **提交今日打卡**；提交时会重新获取实时位置，经学校定位校验后提交，并回查服务器结果。
4. 需要自动执行时，勾选 **启用自动打卡**，设置检查时段和间隔，点击 **保存打卡设置**。默认关闭；默认检查时段为北京时间 21:00–23:15，每 300 秒检查一次，提交仍以学校当天任务时段为准。**当天一旦确认打卡成功，当天就不再重复判定**（不再查询学校、也不再自动续期登录），第二天时段到了自动恢复。此外**每天自动续期登录最多 3 次**，用完即停并提示手动登录 —— 自动行为有硬上限，不会无限重试。
5. **定位来源** 可在 *真实定位（Windows / Wi-Fi）* 与 *模拟定位* 之间切换，保存后立即对定位检测、手动提交与自动打卡生效。使用模拟定位时，点击 **在地图上选择位置** 可打开地图选点：拖动平移、滚轮或按钮缩放，点一下落点，标记直接写选点自己的名字，角标实时显示距学校打卡点的距离与是否在允许半径内。保存的点会进入 **已保存的选点** 下拉框（最多 12 个），可以随时切换、**重命名** 或 **删除**；**名称相同即更新那个点，换个名称就是新建**，切换选点不会删除任何一个位置；本机原有采样样本会自动收进列表，不会被覆盖丢失。程序自带两个起始位置（李园一舍、杏园三舍），首次运行即可直接选用。点击 **检测模拟定位** 会明确告诉你当前用的是哪个选点。底图默认来自 OpenStreetMap，拉不到时自动改用高德地图（署名画在地图右下角，跟着实际画出来的底图走），可随时关闭；单张瓦片失败会自动重试，整个底图长时间没有任何瓦片会改用下一个底图源，全部不可用时明确写出「已回退离线网格」并给出 **重试底图** 按钮，而不是只留一张空网格。关闭或离线时仍有离线网格、比例尺与半径圈，选点照常可用。地图只显示选点与学校公布的打卡点，不显示实时定位，选点名称也不进入界面之外的状态快照。

运行条件与限制：

- 需电脑开机、用户登录 Windows、软件保持运行；关闭打卡设置窗口后仍可后台执行。退出整个软件会停止打卡，睡眠期间不运行，恢复后在有效时段内补查。已有“开机自启动”设置会在用户登录时启动托盘及打卡调度。
- 登录 Token 有效时复用，失效时通知重新登录，不自动弹浏览器。仅在**已保存统一认证凭据**时才会自动填写并识别验证码（见上文第 1 条）；未保存凭据则始终由人工完成登录。登录需要已安装的 Edge 或 Chrome。
- 使用真实定位时，每次提交使用 Windows 位置服务数据，拒绝超过 120 秒或误差超过 200 米的定位。Windows 可能无法提供足够准确的位置；不会以校园网在线状态或历史宿舍坐标代替实时定位。
- 1.3.1 起使用 Windows WinRT 定位接口，最多等待约 30 秒取得实时数据，分别提示权限拒绝、服务关闭、无信号、超时、过期或精度不足。默认位置及 IP 粗略位置不用于打卡；授权成功不等于定位一定可用。
- Windows 的 WGS84 坐标转换为表单使用的偏移坐标；学校接口兼容性和定位接受情况尚需真实账号验证。若位置校验不通过，请在学校官方页面处理。
- 同一天存在多条无法唯一确定的任务、字段不完整或任务已过期时停止提交。不支持跨日任务。
- 提交后由服务器写入的记录直接判定成功；响应丢失时回查服务器结果。服务器**确认未记录**时，界面显示服务器给出的原因并在检查时段内自动重试：同一任务最多 3 次、两次之间至少间隔 60 秒，手动提交不受此上限限制。只有在结果完全无法确认（回查也失败）时才显示 **提交结果待确认**，此后仅回查、不重复提交；请在学校页面核实并必要时在那里完成。
- 网络代理和打卡工作线程独立，停止校园网后台检测不会关闭打卡；关闭打卡请在打卡设置中取消勾选并保存。取消当前操作不会关闭自动设置；已发出的提交不能撤回。

打卡数据存放在 `%LOCALAPPDATA%\youziauth\dorm`：Token 使用当前用户范围 DPAPI 单独加密；设置、任务状态与精简历史记录仅保存本机。**清除登录凭据** 同时关闭自动打卡。打卡会向 `of.swu.edu.cn` 发送登录 Token、任务字段及实时位置；登录浏览器访问学校认证站点，Windows 定位由系统服务提供。不要分享该目录。

从源码运行时，先执行 `python -m pip install -r requirements-dorm.txt`。打包执行 `./build_msi.ps1 -InstallDependencies`，登录组件随包分发，不包含浏览器本体。

本次集成以本地 `swu-daka` 提交 `42d8973` 的接口流程为参考；自动化测试使用模拟学校响应，并不代表真实账号已成功打卡。

## 使用要求

- Windows 10 或 Windows 11；
- Microsoft Edge WebView2 Runtime（新版桌面界面需要；仅安装普通 Edge 浏览器不等同于已安装 Runtime）；
- 已连接西南大学校园网；
- 拥有可正常使用的校园网账号；
- 安装和启用开机自启动时可以接受 Windows 管理员授权提示。

普通用户安装 MSI 后不需要另行安装 Python。

## 下载与安装

1. 打开本仓库右侧的 **Releases** 页面，确认 Git Tag 与发布版本一致；
2. 下载 `youziauth.msi`、`SHA256SUMS.txt`、`youziauth.msi.ed25519` 和 `release-provenance.json`；
3. 用 `Get-FileHash -Algorithm SHA256 .\youziauth.msi` 核对哈希与 `SHA256SUMS.txt` 一致；
4. 核对发布签名确实覆盖这个安装包（不需要私钥）：

   ```powershell
   python tools\sign_release.py --msi .\youziauth.msi --version 1.6.7 `
     --verify-signature-file .\youziauth.msi.ed25519
   ```

   或者手动比对 `release-provenance.json` 里的 `release_public_key` 与代码中的
   `windows_update.PUBLIC_KEY_B64` 是否一致。签名与版本、字节数绑定，所以旧版本的签名
   无法用在新版本上。
5. 双击安装包并按照提示完成安装；
6. 从 Windows 开始菜单启动 **youziauth**。

安装过程中如果 Windows 显示安全确认，请停止并重新核对 Git Tag、SHA-256 和发布签名，不要直接绕过提示。

> 由于当前发布物没有商业代码签名证书，Windows 仍可能显示"未知发布者"或 SmartScreen 提示。
> 这不影响上述校验的有效性：自动更新只信任仓库内置的发布公钥，与证书无关。

## 自动更新

程序启动后会自动检查 GitHub 正式版，发现新版本会在后台下载并校验，确认后才调用 Windows 安装向导。

- 校验内容包括：SHA-256 哈希、Ed25519 发布签名、MSI 产品属性，以及安装前持文件锁的重复校验。
- 签名由离线私钥生成，公钥内置在程序里；因此不需要证书也能确认更新来源。
- **从 1.6.6 及更早版本升级需要手动安装一次**：旧版本里没有新公钥，也没有对未签名安装包的信任路径。
  装好之后，后续版本都能在应用内自动更新。

签名与密钥管理的完整说明见 [docs/release-signing.md](docs/release-signing.md)。

## 首次使用

1. 确保电脑已经连接西南大学校园网；
2. 在左侧进入 **校园网**，填写校园网账号；
3. 在“密码”中填写校园网密码；
4. “检测间隔（秒）”建议保留默认值 `60`；
5. 点击 **保存设置**；
6. 点击 **立即检测**，确认连接状态；
7. 如果希望开机自动认证，勾选 **开机自启动**，然后再次保存。

启用或关闭开机自启动时，Windows 会请求管理员授权。这是因为程序需要创建或移除开机认证任务。

## 日常使用

关闭主窗口不会退出程序，而是把它隐藏到系统托盘；托盘不可用时会最小化到任务栏。已运行的后台任务继续执行，关闭窗口本身不会开启新的检测任务。托盘图标会显示当前状态，例如在线、离线、检测中、已停止或错误。

右键单击托盘图标可以：

- 查看当前状态；
- 显示主界面；
- 进入设置；
- 立即检测；
- 退出程序。

如果重复启动 youziauth，程序会提示当前电脑已经在运行。此时请在系统托盘中打开已有实例。

## 设置说明

| 设置项 | 说明 |
|---|---|
| 账号 | 西南大学校园网账号 |
| 密码 | 校园网密码；安装版使用 Windows DPAPI 在本机保护 |

左侧 **运行记录** 可在校园网和寝室打卡记录间切换，点击 **刷新记录** 可重新读取。校园网设置有未保存修改时，先保存再检测；停止后台检测不受未保存设置影响。

## 常见问题

### 点击“检测一次”后认证失败

请依次确认：

1. 当前连接的是西南大学校园网，而不是普通宽带或手机热点；
2. 校园网账号和密码可以在学校认证页面正常登录；
3. 账号没有欠费、停机、达到设备数量限制或被临时锁定；
4. 重新填写密码并保存，然后再次点击 **检测一次**；
5. 查看窗口中的状态和日志，确认服务端返回的具体提示。

如果校园网认证页面或协议发生变化，旧版本可能暂时无法使用。请查看 Releases 中是否有更新版本。

### 提示服务类型错误

从源码运行时，可以把配置文件中的 `service` 留空后重试：

```ini
service =
```

安装版没有暴露该高级选项。如果持续出现此错误，可以先使用学校网页认证，并关注后续版本。

### 开机后没有自动认证

- 打开设置，确认 **开机自启动** 已勾选并保存；
- 如果保存时出现管理员授权窗口，请选择允许；
- 在主界面点击 **检测一次**，先确认账号本身能够认证；
- 如果状态显示“系统认证代理未运行”或日志长时间不更新，请点击 **修复系统代理** 并批准管理员提示；
- 如果 Windows 安全中心显示对 `youziauth-agent.exe` 的检测，不要关闭 Defender，也不要排除整个安装目录。请先核对 GitHub Release 公布的发布签名、SHA-256 和版本号，再通过项目 Issue 和 Microsoft 文件分析入口报告误报；
- 修复完成后确认状态时间和日志都已更新。只能看到旧日志并不代表后台代理仍在运行；
- 如果使用手机热点或其他已经可以上网的连接，程序会主动跳过校园网认证。

### 关闭窗口后找不到程序

主窗口关闭后会隐藏到系统托盘。点击任务栏右侧的托盘展开按钮，找到 youziauth 图标，然后右键选择 **显示主界面**。

### 收到“校园网认证失败”通知

通知中可以选择：

- **重新认证**：立即重新尝试；
- **打开设置**：检查账号、密码和日志；
- **本次不再提醒**：在本次 Windows 启动期间停止重复提醒。

下次重新启动 Windows 后，提醒抑制会自动重置。

### 自动打卡一直失败，提示“TLS 握手被切断”或“加密连接失败”

先看是不是代理引起的：如果本机开着 Clash 等代理工具，**请确认它处于“规则”模式，而不是
“全局”模式**。全局模式会把发往学校接口的流量也送到境外节点，学校入口会在 TLS 握手完成前
直接切断（表现就是连续失败、每次约 5 秒）。切回规则模式后立即恢复；程序会在连续失败 5 次时
把这条建议一并弹出来。

其余情况可以打开“运行记录”：每条失败都带受控诊断（失败类别、耗时、走了直连还是系统代理、
本轮重试了几次），据此判断是本地网络、代理还是学校接口的问题。

## 安全与隐私

youziauth 不包含遥测或第三方数据收集功能。校园网认证时，账号和密码只会发送到配置的校园网认证地址。可选寝室打卡功能的数据发送范围见上文“寝室打卡”。

安装版将配置和 DPAPI 凭据保存在：

```text
%ProgramData%\youziauth\config.ini
%ProgramData%\youziauth\credential.dat
```

密码不会以明文形式写入安装版的 INI 文件。DPAPI 凭据只能在相应 Windows 环境中解密，但仍不应复制或分享给他人。

若启用了寝室打卡的**统一认证静默登录**，会额外保存一份统一认证凭据（默认不保存）：

```text
%LOCALAPPDATA%\youziauth\idm\credential.dat
```

它同样使用当前用户范围的 DPAPI 加密，只保存在本机、只能被同一 Windows 用户解密。
本机被完全控制时该凭据可被解密，这与所有「记住密码」功能的风险相同；介意请不要保存，
不保存时登录流程与以前一致（人工输入）。详见 [SECURITY.md](SECURITY.md)。

向他人寻求帮助前，请隐藏或删除以下内容：

- 校园网账号和密码、统一认证学号与密码；
- 完整登录地址及其查询参数；
- MAC 地址、设备 IP 和其他网络标识；
- 未经处理的配置文件、凭据文件、日志和截图。

安全问题报告说明见 [SECURITY.md](SECURITY.md)。
